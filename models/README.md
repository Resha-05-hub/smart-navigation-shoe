# Models Directory

This directory stores deep learning model weights used for computer vision object detection in the Smart Navigation Shoe project.

## Models Overview

* `yolov8n.pt`: Default Lightweight YOLOv8 Nano model weights for object detection.

## Next Phase Setup

In Phase 2, download pre-trained YOLO weights (e.g. `yolov8n.pt`) and place them here, or configure `config/config.yaml` to specify your custom model location.
